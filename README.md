# 题夹

一个 Mac 上的阅读理解练习客户端：短篇单题、一拖五、计时、解析和本地练习记录。

**[下载与安装](https://piggydance.github.io/tijia-releases/) · [最新安装包](https://github.com/PiggyDance/tijia-releases/releases/latest) · [首次打开说明](INSTALL.md)**

无需购买模型 API Key，无需登录即可使用共享阅读题库。首个公开版本 0.7.0 内置 10 题，联网同步后续新题。题型由题库描述，客户端不固定题型名称。

本仓库用于公开安装包、原创共享题库及题库恢复资料，当前未包含客户端完整源码。个人作答与登录信息不会发布到这里。题目仍可能存在歧义，欢迎通过 Issues 反馈练习标题与题号。

免费托管：GitHub Pages 提供下载说明和默认题库入口，GitHub Releases 提供安装包，Cloudflare Workers Static Assets 提供相同题库的镜像。网络不可达时可继续练习安装包内或此前同步的题目。

此版本尚未经过 Apple 公证，首次启动可能需要在系统设置中确认打开，详见安装说明。
